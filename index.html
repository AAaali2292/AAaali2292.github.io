Python · GitHub Actions

ERCOT day-ahead power price forecast

Every day the code posts tomorrow's hourly Texas hub price to GitHub before ERCOT's day-ahead market closes, and scores it once the real price clears. The forecast is a regression on load, wind and solar. A merit-order stack built on Henry Hub gas, with a 400-path Monte Carlo, explains why the price sits where it does.
